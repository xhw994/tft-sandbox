# 云顶沙盘 (TFT Sandbox)

纯静态、零后端的云顶之弈阵容推演与补强工具，支持暗黑战术沙盘 / 明亮战术白图双主题切换、已有装备亲和分配、解锁弈子前置规划、羁绊天梯追踪与右键可撤销屏蔽。所有状态保存在浏览器本地（`localStorage`），全站零第三方外链请求，国内/国外及本地离线均可直接打开。

## 核心能力

- **战术棋盘**：拖拽摆棋/换位、单击选中编辑、双击升星、右键级联卸装/降星/移出、快捷键 `1/2/3` 切星、`Del` 移出、`/` 聚焦搜索、`Esc` 退出预览。
- **已有装备 & 亲和推荐**：固定 2 行 `6×2` 已有装备池与真实纹章快选；自动按「坦克 / 战士 / 输出 / 功能 × AD / AP」8 维特征为主 C / 主坦分配未穿戴装备，并对剩余散件在下一步购买与补强方案中标注 `契合XXX`。
- **解锁目标构筑**：以指定需解锁弈子上场为前提推演阵容，自动置顶缺失解锁前置弈子；对多羁绊解锁条件（如 8 羁绊）自动启用小型羁绊天梯追踪与棋盘幽灵预览。
- **玩法模式 & 羁绊天梯**：支持普通补强、赌狗低费、高费运营（84/95）及羁绊天梯（含开局纹章引导、目标羁绊数与等级上限约束）。
- **推荐右键禁用**：右键推荐弈子进入 1.2s 可撤销倒计时，抽离后本局不再推荐，随时可从底部 `已屏蔽` 栏恢复。
- **跨赛季扩展**：通过右上角「设定 ▾ → 导入/导出赛季 JSON」可切换或备份自定义赛季数据。

## 本地使用与开发

```bash
npm install
npm test        # 运行全量单元测试（board / assess / engine / new_features）
npm run dev     # 本地热更新开发预览
npm run build   # 生成单包静态产物至 dist/（同时兼容 HTTP 托管与本地 file:// 双击）
```

Windows 下构建完成后可直接双击 `启动.bat` 打开 `dist/index.html`（地址栏末尾加 `?demo=1` 可载入演示阵容）。

## 线上部署（国内 + 海外）

本项目为纯静态站点，推荐一份 GitHub 仓库驱动双入口自动同步：

- **海外 / 开源默认入口（GitHub Pages）**：推送至 `main` 分支后，`.github/workflows/deploy-pages.yml` 自动执行测试、构建并发布至 `https://xhw994.github.io/tft-sandbox/`。
- **国内 + 海外直连入口（腾讯云 EdgeOne Pages 免费版）**：在 EdgeOne Pages 控制台绑定本 GitHub 仓库，会自动读取根目录 `edgeone.json`（构建命令 `npm run build`，输出目录 `dist`，已配置静态资源长期缓存与 `index.html` 协商缓存）。
